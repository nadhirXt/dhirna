# Code de conduite

## Notre engagement

Pour garder **Dhirna** accueillant pour les étudiants, utilisateurs et contributeurs de tous niveaux, nous nous engageons à maintenir un espace respectueux, sans harcèlement ni discrimination, quel que soit l'âge, l'expérience technique, l'origine, le genre, le handicap ou la neurodivergence.

## Comportements attendus

- Utiliser un langage clair, constructif et respectueux dans les issues, Pull Requests et discussions.
- Accueillir les retours critiques de bonne foi, en particulier sur l'ergonomie, la vie privée et les bugs.
- Respecter l'objectif éthique du projet : Dhirna sert uniquement à l'auto-contrôle personnel sur ses propres appareils.

## Comportements inacceptables

- Insultes, attaques personnelles, moqueries ou harcèlement public ou privé.
- Publication d'informations privées d'une autre personne (adresse IP, identifiant, capture personnelle).
- Propositions visant à transformer Dhirna en outil de surveillance cachée ou de contournement du consentement.

## Application

Les comportements contraires à ce code peuvent être signalés au mainteneur via l'onglet Security ou le profil GitHub `@nadhirXt`.

Inspiré du [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
